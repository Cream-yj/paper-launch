# Paper Launch

面向 CS 顶会论文的写作 skill，减少 GPT 式防御性表达，把研究写成围绕最强贡献与证据展开的论证。

**论文是发布会，不是工作汇报。** 以“问题 → 缺口 → 思路 → 最硬的结果”组织叙事，主动讲清楚优势；对已有文字逐处指出问题，并给出可以直接替换的改法。

## 适用任务

- 起草与修改摘要、引言、贡献、方法、实验分析和结论。
- 去掉自我削弱、重复犹疑和按尝试过程展开的表达。
- 为每个实验确定论证职责，让表格中的优势进入正文。
- 用有证据的目标差异或权衡解释结果，保留必要事实与比较条件。

支持中英文。解释默认使用中文，改写沿用论文语言。它强化表达，不制造结果、隐去反证或偷偷改变评价标准。

## 使用

将整个仓库放入支持 `SKILL.md` 的工具的 skill 目录。Codex 的默认安装方式：

```bash
git clone https://github.com/Cream-yj/paper-launch.git ~/.codex/skills/paper-launch
```

调用示例：

```text
请使用 $paper-launch，按发布会原则检查下面这段论文文字中的防御性写作。
逐处给出：原句、问题、可直接替换的改法，最后给连贯改写。
请保留所有结果、数值、比较条件和必要限定。

〔在这里粘贴论文文字〕
```

```text
请使用 $paper-launch，根据我提供的方法和实验结果重组引言。
先提炼一个核心贡献，再按问题、缺口、思路、最硬的结果展开。
材料没有支持的结论不要补造，缺少的证据单列为作者待办。
```

有些工具需刷新或重新开启会话才能发现新安装的 skill。对于其他支持 skills 的工具，使用其对应的安装目录，保留仓库结构即可。

## 文件结构

- [SKILL.md](SKILL.md)：九条发布会原则、审阅流程、改写策略和输出约定。
- [references/examples.md](references/examples.md)：虚构案例，演示改写力度和证据边界。
- [agents/openai.yaml](agents/openai.yaml)：Codex 展示名称与默认调用提示。

## 继续迭代

后续用真实使用中遇到的表达问题来改进：保留匿名化的输入、期望改法及理由，在 `SKILL.md` 调整对应规则，或在示例中加入确有帮助的对照。避免为每次个例不断增加通用禁令。

从安装目录拉取已发布的更新：

```bash
git -C ~/.codex/skills/paper-launch pull --ff-only
```

如果该目录已有本地修改，先保留或提交修改再更新。不要将未公开的稿件、实验数据或私人讨论加入这个仓库。
